ESTÚDIO INFANTIL IA - VERSÃO 2

COMO PUBLICAR
1. Descompacte este ZIP.
2. No GitHub, abra o repositório do Estúdio Infantil IA.
3. Faça upload do arquivo index.html para a raiz do repositório, substituindo o antigo.
4. Confirme em Commit changes.
5. Aguarde o GitHub Pages atualizar e abra o endereço do site.

COMO USAR
1. Selecione várias imagens (personagens e cenários).
2. Selecione a música em MP3, M4A ou WAV.
3. Cole uma legenda por linha.
4. Deixe a duração em automático para usar a duração real do áudio.
5. Escolha horizontal ou vertical e o tipo de movimento.
6. Toque em Gerar vídeo completo e mantenha o navegador aberto até terminar.

LIMITAÇÕES IMPORTANTES
- Esta versão anima imagens com movimentos de câmera 2.5D, zoom e deslocamentos. Não cria movimentos corporais 3D reais.
- As legendas são distribuídas igualmente entre as linhas; ainda não há transcrição automática palavra por palavra.
- A exportação depende do suporte do navegador. Safari/iOS pode ter limites de memória e formatos; o arquivo pode ser MP4 ou WebM conforme o suporte detectado.
- A caixa de animação 3D por IA é apenas informativa. Nenhum provedor externo foi conectado e nenhuma chave/API é necessária nesta versão.
- GitHub Pages hospeda os arquivos, mas não é um servidor de renderização. O processamento acontece no navegador do aparelho.
