ESTÚDIO INFANTIL IA — VERSÃO 3

PUBLICAR NO GITHUB PAGES
1. Descompacte este ZIP.
2. No repositório do GitHub, envie index.html e manifest.webmanifest para a raiz, substituindo os arquivos antigos.
3. Faça Commit changes e aguarde o GitHub Pages atualizar.

NOVIDADES
- Referências dos personagens separadas das imagens de cenas.
- Prévia individual das imagens enviadas como cenas.
- Planejador local de roteiro baseado nas legendas, com sugestões simples de personagens.
- Mantém prévia, movimentos e exportação existentes da V2.

IMPORTANTE
O planejador desta versão NÃO é uma IA generativa; ele usa regras simples no navegador. Para ter uma IA como ChatGPT, será necessário conectar uma API por um backend seguro. A API pode ter cobrança separada e não está ativada nesta versão. As referências dos personagens são exibidas separadamente, mas ainda não são enviadas a um gerador de imagens.

LIMITAÇÕES
- As legendas continuam distribuídas igualmente no tempo; não há transcrição automática com marcação temporal.
- A animação continua sendo movimento 2.5D de imagens, não animação corporal 3D real.
- A exportação depende do navegador e pode ser limitada no iPhone.
